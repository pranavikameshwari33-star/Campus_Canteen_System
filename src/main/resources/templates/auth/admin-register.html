Canteen administrator registration

No administrator exists yet. The account you create now becomes the first canteen administrator. After that, new administrators need an invitation code from an existing administrator.
To register as an administrator you need a one-time invitation code. An existing administrator can create one on the Accounts page. Codes are valid for 24 hours.
Local development: the invitation code set in CANTEEN_ADMIN_INVITATION_CODE is also accepted here.
The setup code set by whoever installed the system (CANTEEN_SETUP_CODE).
For example ABCD-EFGH-JKLM-NPQR.
You will log in with this ID, for example CANTEENADMIN02.
